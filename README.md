# Blender 游戏特效 UV 工具

面向游戏特效制作的 Blender 插件。可在 3D 视图里创建环片和条带、编辑 UV、设置顶点透明度，并直接在模型上检查贴图和效果。

**当前版本：0.4.26 · 已测试 Blender 5.3.0**

## 安装

1. 打开 [插件源码](./uv_effects_modifier.py)，点 **Download raw file** 下载 `uv_effects_modifier.py`。
2. 在 Blender 打开「编辑 → 偏好设置 → 插件」，通过「从磁盘安装」选择下载的 `.py`，启用 **UV Effects Modifier**。
3. 回到 3D 视图，按 `N` 打开 **UV Effects** 侧栏。

## 快速上手

1. 展开 **特效网格**，新建环片或条带。工具会自动铺 UV；已有模型也可直接添加 UV Effects 修改器。
2. 在 **UV 编辑** 里给修改器选输入 UV。默认输出为 `UV_Effects`，拉伸、挤压和软偏移会计算到该输出层。
3. 在 **模型贴图预览** 选择贴图，切到「结果 UV」。平铺、偏移、旋转、Wrap 和透明度可直接在模型上查看。点「原材质」退出预览。
4. 要直接编辑当前 UV 层，进编辑模式后选面。左下角 UV 预览会高亮选中的面、边或顶点。

## 工具一览

| 分组 | 功能 |
| --- | --- |
| 特效网格 | 参数化环片与条带；可调整内外半径、弧度、长度、宽度及分段。 |
| UV 修改器 | 曲线拉伸／挤压、软偏移、结果 UV 预览和接缝标记。 |
| 常用 UV 工具 | 选区移动、旋转、缩放；支持自定义锚点、展开与投影。 |
| 逐面 UV | 独立缩放、逐面铺满或压点；直接写当前 UV 层，不新建图层。 |
| UV 排布 | 直线扫描、径向扫描、极坐标、随机保形、逐面压点、逐顶点随机，以及不重叠的随机换格。 |
| 模型贴图预览 | 平铺、偏移、旋转；Repeat／Clamp／Mirror；亮度渐变映射、贴图 Alpha 和亮度去黑。 |
| 效果预览 | 顶点置换和 RG 流向扭曲，可独立设置平铺；可选辉光，不覆盖场景已有合成。 |
| 顶点色 | 编辑选中顶点的 Alpha，写入 `UVFX Color`，可与贴图透明度相乘预览。 |

### 两个实用操作

- **在 3D 视图改 UV**：编辑模式选面后，`Shift+Alt+G` 移动、`Shift+Alt+R` 旋转、`Shift+Alt+S` 缩放。移动与缩放可用 `X`／`Y` 限制 U／V；左键或回车确认，`Esc` 取消。
- **整齐阵列随机换格**：在「UV 排布 → 随机排布」选择「随机换格（不重叠）」。它需要等尺寸、不重叠的现有格位；随机种子只打乱各面与格位的对应关系，不改变整体排布。

## 恢复与导出

- 逐面操作和 UV 排布支持实时预览，取消可恢复本次调整。「恢复原始 UV」恢复当前层首次使用这些工具前的备份，前提是网格拓扑未变化。
- UV 排布可把扫描进度等数据写入 UV；真正的时间动画需在 Unity 材质里驱动。贴图预览、置换、扭曲和辉光不会自动转换成 Unity 材质。导出前请核对 UV 通道、顶点色和所用渲染设置。
- **0.4.26** 修复了「恢复原始 UV」后修改器输入可能变空的问题。如果旧工程的输入已空，手动选回当前 UV 层即可。
